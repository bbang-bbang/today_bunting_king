자동 안전장치

🛡️ 리스크 자동 차단

투자금 상한 고정 — 설정 금액을 초과하는 주문은 자동으로 거부됩니다.

한 종목 집중 방지 — 단일 종목에 전체 자금의 50% 이상 투입 불가

연속 손실 시 중단 — 연속으로 손실이 나면 추가 매수를 자동 차단

🔒 거래 확인 절차

10분 유효 버튼 — 추천 후 10분이 지나면 버튼이 만료되어 충동 매수 방지

PIN 인증 — 큰 금액(투자금의 30% 초과) 주문 시 6자리 PIN 추가 확인

장 시간 외 차단 — 09:00~15:30 이외 시간대 주문 자동 거부

📋 모든 거래 기록

수정 불가 감사 로그 — 모든 매수·매도 내역이 삭제·수정 불가 형태로 보관

증권사 잔고 대조 — 봇 기록과 실제 증권사 잔고를 매번 비교해 정합성 유지
